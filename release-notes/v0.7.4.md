# Denon AVR Plus 0.7.4

**Test the receiver without the jumping screen.**

Needs **Home Assistant 2026.8** or newer. After updating, reload the Home
Assistant app or page once, so it shows the new texts.

---

## Changed

- **The progress names the part of the receiver** that is being tested
  (Audio, Speakers, Video, Receiver, Zone 2, Tuner), not every setting. The
  page reloads to show a new name; it now does so only a few times per step
  instead of for every setting, so the screen no longer jumps.
- **The tests run part by part**: all audio settings, then the speakers,
  the video settings and so on. Quiet and audible tests stay apart, as
  before.

## Tested

- 522 tests pass on Home Assistant 2026.8 and 2026.10; ruff, the typing
  baseline, the coverage floors and the repository checks pass.
