# Denon AVR Plus 0.7.3

**Fixes to Test the receiver from the runs on an AVR-X2600H and an
AVR-X2000.**

Needs **Home Assistant 2026.8** or newer. After updating, reload the Home
Assistant app or page once, so it shows the new texts.

---

## Fixed

- **The percentage** no longer turns into an endless spinner while a step
  runs. The page reloads for every setting to show its name, and the
  percentage now comes again after each reload.
- **Names that say little alone** carry their device: "Graphic EQ: Enabled"
  instead of "Enabled", and the same for Zone 2.
- **The checklist** on the progress page is a set of lines; as a centred
  list its bullets stood apart from the items.
- **Tone control, bass and treble** are tested with Dynamic EQ off for the
  moment while MultEQ is on: an AVR-X2600H with Audyssey on ignored tone
  control while Dynamic EQ was on. With MultEQ off, Dynamic EQ is left alone.
- **The graphic EQ** counts as a missing precondition while MultEQ is on
  (it works only with MultEQ off, and switching MultEQ is heard).
- **Auto standby** is tested with 60 minutes: the AVR-X2600H ignored 8 hours.

## Tested

- 520 tests pass on Home Assistant 2026.8 and 2026.10; ruff, the typing
  baseline, the coverage floors and the repository checks pass.
- The command tests of an AVR-X2600H (firmware 3.139.175) and an AVR-X2000
  are kept as test data. A test checks that each setting they confirmed is
  written and read back in the form the receiver echoed. Confirmed there,
  among others: the Audyssey settings, the volume settings, timers, ECO,
  the display, the HDMI outputs, All Zone Stereo, `Z2SOURCE` (it turns
  Zone 2 on) and the setup menu (`MNMEN ON/OFF`).
- Still open: Auto Lip Sync on the AVR-X2600H (it does not report
  `SSHOSALS`), the auto standby values it offers, and a mute that came back
  off at once.
