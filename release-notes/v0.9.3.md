# Denon AVR Plus 0.9.3

**A quieter connection, names that say what they do, no test request for
receivers that are already checked, and value formats that follow the
receiver's generation.**

Needs **Home Assistant 2026.8** or newer. After updating, reload the Home
Assistant app or page once, so it shows the new texts.

---

## New

- **Sources and sound modes in any spelling.** `select_source` and
  `select_sound_mode` find an input by its shown name, the receiver's name
  or its code, in any case. An unknown name gives a translated error that
  lists the names that work.
- **An input Zone 2 cannot play stays hidden.** When Zone 2 does not switch
  to an input (an AVR-X2600H plays no HDMI input there), the input is taken
  out of the Zone 2 list for good. To bring it back, add it under Configure →
  Sources.
- **Checked receivers and their siblings ask for no test.** The AVR-X2600H
  and AVR-X2000 are now known models, so setup offers no capability check
  and no repair asks for one. The same goes for their siblings, by the
  manufacturers' documents: the AVR-E400, Denon's other 2019 receivers
  (AVR-X1600H, S950H, S750H, S650H) and Marantz's 2019 AV receivers (SR6014,
  SR5014, NR1710, NR1510). Reports from them are still welcome.
- **Headphone EQ** appears when the receiver answers for it at setup (it
  starts disabled). Before, it waited for a function name no receiver sends.
- **HEOS lines in the diagnostics**, next to the telnet lines; account data
  is removed.
- **Voice assistants and Apple Home**: a new section in the user guide on
  what Assist, Google, Alexa and Apple Home can do with the receiver.
- **Receiver reports**: a form in GitHub Discussions and a list of models
  known to work in CONTRIBUTING.

## Changed names

- **Dialog Level is now Center Level** (Center-Pegel): it is the receiver's
  Center Level Adjust.
- **Music is now Network Music** (Netzwerk-Musik): the switch turns the zone
  to the network input.

Entity ids stay as they are; only the shown name changes. New setups get
`…_audio_center_level` and `…_network_music`.

## Fixed

- **A receiver no longer asks itself in circles.** An AVR-X2600H repeats its
  signal lines after each query; the integration answered each repeat with
  a new query, twice every 3.6 seconds. It now asks again only when the
  signal really changed.
- **Receivers from 2014 and 2015 get their own value formats.** The
  integration picked the AVR-X2000's formats for every receiver on port 80.
  Receivers from 2014 and 2015 (AVR-X1100W to X4200W, SR6011 and others)
  use the newer ones, as their documents give them: picture levels from
  −50 to +50 and tuner presets 01–56. The generation now comes from what
  the receiver reports, and shows in the diagnostics.
- **M-DAX Medium** is sent as `MID`, as Marantz's protocol table gives it;
  before it went out as `MED`, which Marantz receivers do not know.
- **Audio delay** goes up to 500 ms in 1 ms steps on receivers from 2016
  on (Denon's 2020 table); older receivers keep 0–200 ms.
- **Zone 2 front levels** move in whole dB, the only steps the receiver
  takes.

## Documentation

- The protocol pages explain the receiver generations (`CommApiVers`) and
  how the integration reads values for each.
- References for Denon's 2020 and 2022 tables and Marantz's 2019 table.

## Behind the scenes

- The GitHub actions of the checks are pinned to fixed versions.
- The integration is listed under Media & entertainment → Speakers & audio.

## Tested

- 659 tests pass on Home Assistant 2026.8 and 2026.10; ruff, strict typing,
  the coverage per module and the repository checks pass.
- The connection fix comes from the diagnostics of an AVR-X2600H (firmware
  3.139.175). The other fixes follow the manufacturers' documents and the
  recordings of an AVR-X2600H and an AVR-X2000; they are not yet confirmed
  on a receiver.
