# Denon AVR Plus 1.3.0

**A start without waiting for the receiver, a sensor for what each zone
plays, a "Why no sound?" check, and linked players that switch on with
their input.**

Needs **Home Assistant 2026.8** or newer. After updating, reload the Home
Assistant app or page once. Read
[Upgrading](https://github.com/johnnyh1975/ha_denonavr_plus/blob/main/docs/UPGRADING.md):
there are two new entities per zone.

---

## New

- **Faster start.** From the second start on, the entities are built from
  the last state the integration knew (inputs, speakers, channels, quick
  selects, the setup menus and their values), and the setup does not wait
  for the receiver: only its device description is read first. The rest is
  asked in the background, and the current values follow within a few
  seconds. That state is saved at each start and 10 seconds after a change,
  so a speaker or trim change made before a restart is what the next start
  shows. If the receiver then reports other capabilities (a firmware
  update, another speaker group, a new menu), the integration sets itself
  up once more. The diagnostics show whether a start came from the last
  one (`fast_start`).
- **Activity sensor per zone:** off, announcement, music, radio, film, TV,
  game or on, from the linked player's media type and then the input. For
  automations such as dimming the lights for a film.
- **Why no sound?** A button per zone and the action
  `denonavr_plus.why_no_sound` check the zone and say in plain words what
  stops the sound: no telnet connection, zone off, muted, volume very low,
  Zone 2 following a main zone that is off, an input the zone refused,
  HDMI audio going to the TV, speakers B, a linked player that does not
  play, or no signal at the input. With `fix`, it switches the zone on,
  unmutes it or sends HDMI audio to the receiver.
- **Linked players:**
  - **Switch the player on and off with the input** (per input, off by
    default): a zone switching to the input switches the player on; when
    every zone that played it is off, the player goes off too.
  - **A suggestion** when you link an input: a player whose name matches
    the input, or for the network input the Music Assistant player with the
    receiver's name, is preselected when it is the only match.
  - A Music Assistant player that Music Assistant built from this
    integration's own zone player can no longer be linked; play would go
    back and forth.
- **Questions** in the user guide, and a *No sound* row under
  troubleshooting.

## Fixed

- The start of an AVR-X2000 waited 8 seconds for channel levels it never
  sends; it now takes the trims it does send.

Found in an independent review before the release: the signal sensors were
missing after each fast start; a control answered once made every start set
up the entities again; the setup menus were lost when the setup interface
did not answer; linked players were switched at the first report after a
start and during announcements; Zone 2 on *Source* was judged by its own
input instead of the main zone's.

## Tested

- 959 tests pass on Home Assistant 2026.8 and 2026.10; ruff, strict typing,
  the coverage per module and the repository checks pass.
- Not yet tried on a receiver: how long a fast start takes on the
