# Denon AVR Plus 0.3.3

**Older receivers such as the AVR-X2000 get their Audyssey, tone and
other settings and a full sound mode list.**

Needs **Home Assistant 2026.8** or newer. Nothing to change when coming
from 0.3.2. Coming from 0.3.1: [upgrade notes →](../docs/UPGRADING.md#from-031)

---

## Fixed

- **Settings missing on older receivers.** An AVR-X2000 names few functions
  in its device description, and entities were created only for named
  functions. So it got no MultEQ, Dynamic EQ, Dynamic Volume, reference
  level, bass and treble, LFE, Cinema EQ, loudness, input mode or video
  settings, although it answers all of them. A setting whose name is
  missing now appears when the receiver answers its query at setup.
  Contrast, brightness and saturation are left out of this: older
  receivers use another scale for them.
- **Sound modes on older receivers.** The AVR-X2000 does not list its sound
  modes, so the list held only the active one. It now holds the modes the
  receiver names in its device description that have a command in its
  protocol document; Multi Ch Stereo is sent as `MCH STEREO`.
- **Receiver type.** A receiver on port 80 showed the type `avr-x-2016` in
  the diagnostics; it is `avr-x`, as in the official integration.

## Confirmed on a receiver

The capability check of an AVR-X2000 is part of the tests and the protocol
docs. Every answer goes through the parser in a test.

## Tested

- 369 tests pass on Home Assistant 2026.8 and 2026.10; ruff, the typing
  baseline (down from 86 to 83 findings), the coverage floors, the
  translation, locale-slug and icon checks pass.
- Each fix has a test that fails without it.
- The fixes follow the diagnostics and capability check of an AVR-X2000;
  the new version has not been on a receiver yet.
