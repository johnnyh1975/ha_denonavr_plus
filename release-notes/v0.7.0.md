# Denon AVR Plus 0.7.0

**Hidden entities shown by group, and a command test that tries which
commands your receiver takes and puts everything back. Also everything of
0.6.1, which was not published as a release of its own.**

Needs **Home Assistant 2026.8** or newer. Nothing to do when updating.

---

## New

### Entities by group

- **Configure → Entities** shows the entities that start hidden, a group at
  a time: Audio, Speakers, Video and picture, Graphic EQ, Zones, Receiver,
  Diagnostics. Only groups with hidden entities are offered.
- A group shows only what the integration hid. An entity you enabled or
  disabled yourself stays as it is, and speaker entities of channels the
  receiver does not have stay hidden. Removing a group hides again only what
  it showed.
- Works while the receiver is off. Shown entities appear within half a
  minute, when Home Assistant reloads the integration.

### Command test (from 0.6.1)

- **Configure → Test commands.** Each test reads a setting, writes a
  different valid value, waits up to 2 seconds for the receiver to confirm
  it, asks again, then writes the old value back and checks that it is back.
  Two groups:
  - **Quiet**: tone, Audyssey, surround and picture settings, timers, the
    display, ECO, Zone 2 levels, and the volume 0.5 dB down and back.
  - **Audible and visible**: mute, MultEQ and Dirac, front speakers,
    speaker preset, HDMI and audio output, output resolution, input mode,
    volume limit, All Zone Stereo, Zone 2 following the main zone, a Zone 2
    quick select, the tuner's frequency and preset (while a zone plays the
    tuner), and the setup menu opened and closed on the TV.
- Never tested: power, the 12 V triggers, the Bluetooth transmitter, the
  input, the sound mode, and anything that stores or resets. The main
  zone's settings are tested only while it is on. A stopped test still puts
  its setting back; for All Zone Stereo, the volume limit and a quick select
  the zones are put back as well.
- The result per command (confirmed, only by the query, only by the echo,
  no effect, rejected, no value, skipped, interrupted, and whether the old
  value came back) goes into the diagnostics file, for the device-support
  issue.
- A model that has not been checked yet is offered the test when it is
  added, next to the capability check, with both groups off. It then runs
  once the receiver is connected, after the check, and a message links to
  the prefilled issue. Setting up a known model asks nothing.

## Tested

- 506 tests pass on Home Assistant 2026.8 and 2026.10; ruff, the typing
  baseline, the coverage floors, the translation, locale-slug and icon
  checks pass. The new tests fail without the new code.
- The command test runs against a simulated receiver with its quirks (no
  echo, no effect, a rejection, an echo the query contradicts, a value that
  does not come back, a lost connection, a cancelled test). Not run on a
  receiver yet; its results on the AVR-X2600H and the AVR-X2000 will settle
  the command formats still marked as assumed.
