# Denon AVR Plus 1.2.0

**The device on an input, on the receiver's player: link an Apple TV, a
streamer or Music Assistant to its input, and one card shows and controls
what you hear.**

Needs **Home Assistant 2026.8** or newer. After updating, reload the Home
Assistant app or page once, so it shows the new texts. Read
[Upgrading](https://github.com/johnnyh1975/ha_denonavr_plus/blob/main/docs/UPGRADING.md):
sound mode names in capitals change.

---

## New

- **A linked media player per input** (Configure → Playback). Pick an input,
  then the media player of the device on it. Every zone that plays the input
  shows the player's title, artwork, position and state, and play, pause,
  stop, skip, seek, shuffle and repeat go to it; power, volume and the input
  stay the receiver's. Per input:
  - **Main zone switches to this input when the player starts.** While one
    input follows, a switch from one linked input to another pauses the
    player left behind. The event `denonavr_plus_input_followed` tells
    automations.
  - **Keep the player at full volume**, as the volume is set on the
    receiver. Not offered on the network input.
- **Music Assistant on the network input.** Link it to Music Assistant's
  player of the receiver: the card shows what Music Assistant plays, skip,
  shuffle and repeat go to its queue, its library is a folder in the
  receiver's media browser, and a voice search on the receiver finds it
  ("play Queen on the living room receiver"). With Music Assistant's player
  controls on the zone's Network Music switch (power) and this integration's
  media player (volume) it acts as one device. The guide says how to set it
  up over HEOS, AirPlay or DLNA.
- **The linked players' libraries in the media browser**, one folder per
  player ("Apple TV (DVD)"); playing from it switches the zone to the input.
- **Voice search through linked players** that can search, after the
  receiver's own exact and prefix matches.
- **Pause the linked player when the zone is switched off** (on by
  default): switching a zone off in Home Assistant pauses the player of the
  input it played, unless another zone still plays it; with the main zone
  off putting the receiver in standby, every zone's player.
- **Playing or idle by the input signal** (off by default): a zone on an
  input without a linked player shows *Playing* or *Idle* instead of *On*.
- A renamed linked player stays linked; one that is gone raises a repair
  that unlinks it. The diagnostics show the options and each linked player.
- After setup, a text names the next steps.

## Changed

- **Sound mode names in capitals** (AVR-X2000 and other receivers before
  2016) show as words when they are words only: *Pure Direct* where it said
  *PURE DIRECT*. Choosing by the receiver's name still works; **Readable
  names** off keeps the capitals.
- **New setups** start with the firmware binary sensor and the tuner preset
  and frequency disabled. Existing setups keep their entities.
- Announcements over HEOS pause no linked player and switch nothing.

## Fixed

- A receiver that lists its network input as NETWORK gets `SINET` (Zone 2:
  `Z2NET`), as the protocol has it. Zone 2 took `Z2NETWORK` as refused and
  dropped the input from its list; if it is missing, put it back under
  Configure → Sources.
- The sound mode select is never empty: it shows the current mode when the
  receiver reports only its token, and every mode when it lists no groups.

Found in three independent reviews before the release, among them: an
announcement refused without HEOS, a second announcement right after the
first and switching off during one no longer leave the zone on the network
input or switch it on again; on the network input HEOS keeps its own title
and controls while Music Assistant does not play; a linked player that
hangs or fails no longer holds up a turn off or a search.

## Tested

- 892 tests pass on Home Assistant 2026.8 and 2026.10; ruff, strict typing,
  the coverage per module and the repository checks pass. The options and
  the player were clicked through with the simulated receiver.
- Not yet tried on a receiver: Music Assistant on the network input (HEOS
  on an AVR-X2600H, AirPlay on an AVR-X2000), voice search and pausing on
  turn off with Music Assistant, Music Assistant in a Sendspin group, and
  playing or idle by the input signal (whether every model reports the end
  of a signal).
