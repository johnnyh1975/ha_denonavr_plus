# Denon AVR Plus 0.3.4

**The AVR-X2000 and other older receivers now really get their Audyssey,
Cinema EQ, loudness and video settings, and later starts no longer ask the
receiver which settings it has.**

Needs **Home Assistant 2026.8** or newer. Nothing to change when coming
from 0.3.3. Coming from 0.3.1: [upgrade notes →](../docs/UPGRADING.md#from-031)

---

## Fixed

- **Settings of older receivers.** 0.3.3 asked an older receiver at setup
  which settings it has, about 70 queries 80 ms apart. An AVR-X2000 answered
  the first ~20 and dropped the rest, so MultEQ, Dynamic EQ, Dynamic Volume,
  reference level, Cinema EQ, loudness, input mode and the video settings
  were still missing. A receiver on port 80 now gets one query at a time,
  each after the previous answer (at most 250 ms).

## Changed

- **Setup answers are kept.** Which model-dependent settings a receiver has
  is asked once and kept with its model and firmware. Later starts use the
  kept answers; they ask again after a firmware update or when a release
  adds settings. Answers are kept only when the receiver was on. A
  capability check stands in for these questions, so a receiver that has
  been checked starts without them.

## Tested

- 379 tests pass on Home Assistant 2026.8 and 2026.10; ruff, the typing
  baseline, the coverage floors, the translation, locale-slug and icon
  checks pass.
- Each change has a test that fails without it, among them a fake receiver
  that drops queries arriving while it still answers.
- The fix follows the diagnostics of an AVR-X2000 before and after a
  capability check; the new version has not been on a receiver yet.
