# Denon AVR Plus 1.6.0

**Options that show only what can be done now and save as you go, fewer
repairs, quick select buttons, and edge cases from an independent review.**

Denon AVR Plus is now in the **HACS default list**: search for it in HACS
(the Marketplace) instead of adding the repository yourself.

Needs **Home Assistant 2026.8** or newer. After updating, reload the Home
Assistant app or page once. Read
[Upgrading](https://github.com/johnnyh1975/ha_denonavr_plus/blob/main/docs/UPGRADING.md):
Playback and Activities in the options work differently.

---

## New

- **Quick select buttons**: one button per quick select on the receiver's
  device, and on Zone 2 when it answers; Zone 2's start disabled.
- The device page shows the receiver's **generation** (`CommApiVers`) as
  model id.
- The **logbook** says in words when the receiver switched to an input
  because its linked player started.
- An **"I want to …" table** at the start of the user guide leads from a
  task to the entity, option or action.

## Changed

- **Options menu:** it shows only what can be done now (no Sources before
  the integration is set up, no receiver test while the receiver is not
  connected, Entities only while a group has something to show or hide).
- **Playback** and **Activities** open a short menu, and each step saves
  when it is submitted; there is no *Save* step at the end any more. An
  activity asks its name and zone first, then only the fields that zone
  takes.
- **Zone 2 inputs** are chosen once without asking: every input, or every
  input but the HDMI ones when the receiver reports no HDMI for Zone 2.
  Change them under **Configure → Sources**. The repair that asked is gone.
- **Help support your model** is a notification instead of a repair.
- The signal-based playing state option is marked **Experimental**.
- **Distances** of a speaker removed on the receiver are hidden like its
  channel level.

## Fixed

- A receiver still starting that answers without the model it named before
  is tried again a little later, with its own message, instead of setting
  up entities named "Denon AVR". A receiver that never names its model is
  set up as before.
- Two inputs the receiver itself names alike (an input named "Tuner" beside
  the tuner) no longer block saving input names.
- An activity whose zone was hidden, or whose input left the zone's list,
  can still be saved or deleted.
- Choosing every input for Zone 2 in the options stays; the one-time
  preselection no longer takes it for "never chosen".
- Showing Zone 2 later reloads the entry once, not twice.
- The HDMI preselection for Zone 2 also knows the inputs by the names of
  the receiver's device description (CBL/SAT, Blu-ray, Media Player).
- From Frenck's review for the HACS default list:
  - `play_media` refuses a web address with a control character such as a
    line break; it would have ended the HEOS command early and sent the
    rest as a second command;
  - the release zip no longer contains `__pycache__` folders.

## Tested

- 1066 tests pass on Home Assistant 2026.8 and 2026.10; ruff, strict typing,
  the coverage per module and the repository checks pass.
- An independent review of the release found the edge cases above; each
  fix comes with a test that failed without it.
- Not yet tried on a receiver: the quick select buttons for Zone 2
  (`Z2QUICK<n>`) and the retry of a receiver still starting.
