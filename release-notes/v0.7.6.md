# Denon AVR Plus 0.7.6

**Fixes to Test the receiver from the AVR-X2600H run with 0.7.5.**

Needs **Home Assistant 2026.8** or newer.

---

## Fixed

- **Bass and treble** are tested with the step the receiver publishes. The
  test moved them by half a dB, which an AVR-X2600H (whole dB only)
  ignored, so they always showed "No effect".
- **Zone 2 quick select** with Zone 2 off counts as a missing
  precondition, like the other Zone 2 settings.

## Tested

- 531 tests pass on Home Assistant 2026.8 and 2026.10; ruff, the typing
  baseline, the coverage floors and the repository checks pass.
- The AVR-X2600H run with 0.7.5 is kept as test data: everything was put
  back, All Zone Stereo included, and 23 settings were confirmed, now also
  mute, both HDMI outputs, the volume limit and the setup menu.
- For the settings that still show "No effect" (dynamic compression, LFE,
  dialog control, the video settings, input mode), a run with a source
  playing through the receiver is planned.
