# Denon AVR Plus 0.6.1

**A command test: which commands your receiver takes, tried on the receiver
and put back. In the options, and offered when adding a receiver.**

Needs **Home Assistant 2026.8** or newer. Nothing to do when updating.

---

## New

- **Test commands** (Configure → Test commands, and a skippable step when a
  receiver is added). Each test reads a setting, writes a different valid
  value, waits up to 2 seconds for the receiver to confirm it, asks again,
  then writes the old value back and checks that it is back. Two groups:
  - **Quiet**: tone, Audyssey, surround and picture settings, timers, the
    display, ECO, Zone 2 levels, and the volume 0.5 dB down and back.
  - **Audible and visible**: mute, MultEQ and Dirac, front speakers,
    speaker preset, HDMI and audio output, output resolution, input mode,
    volume limit, All Zone Stereo, Zone 2 following the main zone, a Zone 2
    quick select, the tuner's frequency and preset (while a zone plays the
    tuner), and the setup menu opened and closed on the TV.

  Never tested: power, the 12 V triggers, the Bluetooth transmitter, the
  input, the sound mode, and anything that stores or resets. The main
  zone's settings are tested only while it is on. A stopped test still puts
  its setting back. The result per command (confirmed, only by the query,
  only by the echo, no effect, rejected, no value, skipped, interrupted, and
  whether the old value came back) goes into the diagnostics file. When the
  test was chosen at setup, a message links to the prefilled device-support
  issue on GitHub, as after the capability check.

  At setup both groups are off; the test runs once the receiver is
  connected, after the capability check when that was chosen too.

## Changed

- Adding a receiver of a model that has been checked now shows one step,
  the command test, which can be left off. A model not checked yet gets the
  two test groups next to the capability check.
