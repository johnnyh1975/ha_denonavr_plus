# Denon AVR Plus 0.7.5

**A receiver that stops answering is noticed, and Test the receiver no
longer leaves settings changed when it does.**

Needs **Home Assistant 2026.8** or newer. After updating, reload the Home
Assistant app or page once, so it shows the new texts.

---

## Fixed

- **A silent receiver gets a new connection.** An AVR-X2600H kept the
  telnet connection open but answered nothing more. Home Assistant kept
  showing the old state and its commands went nowhere. Now, when nothing
  comes back for 10 s after a command, the connection is opened again and
  the state is read fresh. Before that, a power query checks whether the
  receiver is only quiet, so queries a model never answers do not count.
- **Test the receiver stops writing when the receiver stops answering.**
  The remaining tests are shown as not run (a new line on the result page)
  instead of "No effect". Once the receiver answers again, the settings
  that did not come back are written back. If telnet stays away, they go
  out over HTTP and are still listed to check on the receiver.
- **Time to settle.** After a test that reloads the sound path (the audible
  ones, Dynamic EQ, Graphic EQ), the test pauses and waits for an answer
  before putting the setting back and before the next one.
- **All Zone Stereo** is tested with Zone 2, no longer right after MultEQ:
  in that order an AVR-X2600H stopped answering (0.7.4).
- **No value is written blind:** a setting the receiver does not report at
  the moment is not tested with what it said earlier.
- **The result page** names settings as their entities do ("All Zone
  Stereo", "Zone 2: Front Left Level") instead of internal keys.

## Tested

- 529 tests pass on Home Assistant 2026.8 and 2026.10; ruff, the typing
  baseline, the coverage floors and the repository checks pass.
