# Denon AVR Plus 0.7.1

**Testing the receiver is one sequence, the entity groups are toggles, and
the texts are shorter.** From the first command test on an AVR-X2000.

Needs **Home Assistant 2026.8** or newer. Nothing to do when updating.

---

## Changed

- **Configure → Test the receiver** replaces Check capabilities and Test
  commands. It runs the capability check, then the quiet command test, then
  asks whether to test what you hear and see (Start or Skip), and ends with
  one result page: questions answered, commands confirmed, not confirmed,
  skipped and not put back, and the link to the prefilled issue. The repair
  for a model not checked yet runs the same sequence.
- **Entities**: a toggle per group, with how many entities it holds and
  what they are, instead of a list of checkboxes.
- **Adding a model not checked yet**: one toggle, "Test the receiver after
  setup" (the check and the quiet test, in the background). The audible part
  needs someone at the TV and is offered in the options. One message points
  to the issue once both have run, instead of one each.
- Shorter texts in the options and at setup, results as a list.

## Fixed

- **A receiver in standby ignores settings**: on an AVR-X2000 in standby
  every quiet test was skipped or had no effect. A main zone that is off is
  now turned on for the command test and off again afterwards, also when
  the test stops.
- Running the audible part no longer drops the quiet part's results from
  the diagnostics; the last result of each part is kept.

## Tested

- 507 tests pass on Home Assistant 2026.8 and 2026.10; ruff, the typing
  baseline, the coverage floors, the translation, locale-slug and icon
  checks pass. The new tests fail without the changes.
- On a receiver: the AVR-X2000's first quiet test (in standby) showed the
  standby problem; `MNMEN?` answers `MNMEN OFF` there.
