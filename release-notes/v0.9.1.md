# Denon AVR Plus 0.9.1

**Auto Lip Sync on newer receivers, and a receiver test that fits the
AVR-X2600H better.**

Needs **Home Assistant 2026.8** or newer.

---

## Fixed

- **Auto Lip Sync** shows its state on newer receivers. They report it on
  its own (`SSALS`), not in the HDMI setup list the AVR-X2000 uses, so the
  switch stayed unknown on an AVR-X2600H. Switching it from Home Assistant
  on these receivers is not confirmed yet.

## Receiver test

- **Input mode** is tested with Auto. Digital does not exist on an input
  that only has HDMI, and the receiver ignored it.
- **Zone 2 following the main zone** is tested with a network or tuner
  source when it already follows, not with the main zone's input: an
  AVR-X2600H did not take its HDMI input by name in Zone 2. Following the
  main zone, it plays it.
- **Subwoofer on/off** is tested in two-channel modes only (Direct, Pure
  Direct, Stereo), the only ones it acts in; in other modes the test says
  so instead of reporting no effect.
- The result records the incoming signal (decoder, format, sample rate).
  Dynamic Compression, Loudness Management, LFE and Dialog Control act on
  Dolby and DTS sound only; with PCM they are taken without an effect.

## Documentation

- The AVR-X2600H page compares what the receiver answered with the
  protocol documents: most queries without a reply are for larger models,
  other regions or newer receivers. It lists what is still to test.
- The tuner section says what the integration reads and controls.

## Tested

- 638 tests pass on Home Assistant 2026.8 and 2026.10; ruff, strict typing,
  the coverage per module and the repository checks pass.
- Two receiver test runs on an AVR-X2600H (firmware 3.139.175), in Multi Ch
  Stereo and in Multi In + Dolby Surround.
