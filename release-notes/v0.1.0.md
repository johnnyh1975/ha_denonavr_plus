# Denon AVR Plus 0.1.0

First release of Denon AVR Plus, an independent continuation of
[Denon AVR](https://github.com/LaserGuruGuy/denon_avr) 1.1.2 by
LaserGuruGuy. Functionally it is that version under a new name.

## What changed

- New integration domain `denonavr_plus` and name "Denon AVR Plus", so it
  can be installed next to the original and the official integration.
- Releases are published as a ZIP that HACS installs directly.

## Upgrading

Nothing is migrated automatically from other Denon integrations yet; see
[docs/UPGRADING.md](../docs/UPGRADING.md).

## Tested

- Unit tests on Home Assistant 2026.8 and 2026.10.
- On a receiver: the code is unchanged from Denon AVR 1.1.2, which its
  author tested on an AVR-X3600H. Not yet tested on other models.
